PC VR demo handbook

In this version the experience runs on the computer and is sent to the VIVE Focus Vision over a USB cable, the way a SteamVR game is. Visitors get the same journey as at the museum station: the button, the intro film, the headset, and the screen shows what they see.

How the visitor presses START in the headset

  • Point either hand controller at START (a thin light beam appears) and pull the trigger under the index finger, or
  • simply look at START for 2 seconds. Useful for visitors who are not holding the controllers.

The headset decides the flow: putting it on at any time shows the headset view straight away, also while “Press the button to begin” is showing or during the intro (the intro then stops). Taking it off, at START or during the film, brings the screen back to “Press the button to begin” after 5 seconds and restarts the experience for the next visitor. Lifting it for a moment and putting it straight back on changes nothing.

One-time setup on the computer

Done once, by whoever installs the computer. It needs an internet connection for the downloads.

  1. Update the graphics driver.
    The computer has an NVIDIA RTX 5080. Install the latest driver from nvidia.com or with the NVIDIA App.
  2. Install VIVE Hub.
    HTC’s free program for the headset, from vive.com. It contains VIVE Streaming, which sends the picture down the cable. Open it once and let it finish its first-time setup.
  3. Install Steam, then SteamVR.
    Both free. Install Steam from store.steampowered.com, sign in, and install SteamVR from inside Steam.
  4. Install “HEVC Video Extensions”.
    From the Microsoft Store. The films are in HEVC format; without this, the film stays black.
  5. Copy and unzip the demo.
    Copy MOI_PC_Demo.zip to the computer. Right-click it › Properties › tick Unblock › OK. Then unzip it to a simple place such as C:\MOI_PC_Demo and keep everything in that folder together.
  6. Put START PC DEMO on the desktop.
    In the folder, right-click START PC DEMO › Send to › Desktop (create shortcut) (on Windows 11, Send to is under Show more options). Staff then start the demo from the desktop.
  7. Run the check.
    Double-click START PC DEMO. It checks the computer and lists anything missing. If it says “No VR runtime is set”: open SteamVR › Settings › OpenXR › Set SteamVR as OpenXR runtime, then try again.
“Windows protected your PC”? The first time the demo starts, Windows may show this because the program is not signed. Click More info, then Run anyway. It does not ask again.

On the headset: turn kiosk mode off

For the museum station the headset is locked to the museum app (kiosk mode). The PC demo needs the headset’s VIVE Streaming app, which kiosk mode blocks. So turn kiosk mode off on the headset used for the demo.

Leave kiosk mode

  1. Press and hold the headset’s own button
    until the Power menu appears in front of you.
  2. Choose Quit Kiosk mode.
  3. Enter the kiosk passcode.
    The 4 to 8 digit code chosen when kiosk mode was set up (write it in “Keep with this handbook” below). The headset returns to its normal home screen.

Going back to the museum station later

In the headset open Settings › Advanced › Kiosk mode and choose Enter Kiosk mode. The earlier choices are kept: our app only, and the same passcode.

Want to keep kiosk mode on? Kiosk mode can allow more than one app. In Settings › Advanced › Kiosk mode, choose several apps and add VIVE Streaming next to the museum app, and keep USB connections on (it covers PC streaming). Check it once with the demo before relying on it.

Opening: start of the day

  1. Switch on the screen and the computer.
    Sign in to Windows.
  2. Connect the headset.
    USB-C cable into the headset and into a USB 3 or USB-C port on the back of the computer (not a hub or a front port). Switch the headset on: hold its power button for a few seconds. Switch on both controllers with their VIVE button.
  3. Link the headset to the computer.
    Open VIVE Hub on the computer and choose the USB connection. In the headset, accept the “connect to PC” message, or open VIVE Streaming from the Library. When the headset shows the SteamVR home, it is linked. If SteamVR does not open on the computer by itself, open it.
  4. Double-click START PC DEMO.
    A small window checks the computer for a few seconds, then the screen shows “Press the button to begin” in full screen and the headset shows the museum room with START.
  5. Do one test run yourself.
    Press the play button, watch the intro, put the headset on when asked. The screen should show your view, with START in front of you. Press START and watch a few seconds of the film.
The demo is ready when the screen shows “Press the button to begin” and the test run worked. If the headset was connected only after START PC DEMO, wait 10 seconds: the experience finds the headset by itself.

Between visitors

  • Wipe the face cushion and the controller grips with a hygiene wipe.
  • Clean the lenses only with a dry microfibre cloth, never with wipes or liquid.
  • Put the headset down with the lenses facing away from windows and bright lights. Sunlight on the lenses can damage the screens inside.
  • Mind the cable: help the visitor keep it behind them, and don’t let anyone step on it or pull it out of the computer.

Staff controls

The film: 8K

START PC DEMO plays the film in 8K (7680×3840), the sharpest picture, which this computer’s graphics card plays easily.

It is the same film file as in the museum headsets, so visitors see the same picture quality in both versions.

Replacing a video. Close the demo first. The intro is intro.mp4 in the demo folder; the film is MOI_PromiseOfSafety\content\journey.mp4. Replace the file with one of the same name. The film must be 8-bit HEVC (the current one, the client’s AlFakher_New, is); a 10-bit file freezes on the first frame in Windows’ video player.

If something goes wrong

What you seeWhat to do
The headset shows the SteamVR home, not the museum roomWait 10 seconds: the experience looks for the headset by itself. If it still doesn’t appear, press Ctrl + Shift + Q, check SteamVR is the OpenXR runtime (setup step 7), and double-click START PC DEMO again.
The headset won’t link to the computer, or VIVE Streaming is missing in the headsetKiosk mode is probably still on: leave it (see above). Check the cable is in a USB 3 port on the back of the computer, unplug and replug it, and choose USB again in VIVE Hub.
The headset and screen say “The film is missing on this device”The film file is gone from the demo folder. Copy MOI_PromiseOfSafety\content\journey.mp4 back from the zip. The message goes away by itself within a few seconds.
The film stays blackInstall “HEVC Video Extensions” from the Microsoft Store, and update the graphics driver (setup step 1).
The headset goes black for a few seconds, then the room comes backThe experience closed (usually SteamVR’s link) and the demo started it again by itself. Once in a while is harmless. If it happens often, tell the technician: the graphics driver and SteamVR on the computer need updating.
The picture in the headset stutters or looks blurryUse a USB 3 port on the back of the computer (not a hub). In VIVE Hub, lower the streaming quality one step.
The play button does nothingCheck the screen shows “Press the button to begin” (the button is ignored during a visit). Press F9 instead, then unplug and replug the button’s cable and wait 10 seconds.
The screen stays on “Please put on the headset” for longIt switches to the headset view as soon as the headset is on. If the screen says “Connecting to the headset…”, the experience is restarting: wait 10 seconds.
Putting the headset on does nothing, or taking it off doesn’t end the visitSteamVR isn’t passing on the headset’s wear sensor. The demo still works with the button and the intro: the headset view comes 12 seconds after the intro, and the visit ends when the film ends. Tell the technician (the app’s log says whether the wear sensor is available).
START is not in front of the visitorHold the left controller’s Menu button for 2 seconds: the room turns to face them.
“Windows protected your PC”Click More info, then Run anyway.
The screen shows the Windows desktopDouble-click START PC DEMO.
Anything elsePress Ctrl + Shift + Q. Close SteamVR and VIVE Hub, switch the headset off and on, link it again (opening step 3), then START PC DEMO. Still wrong: restart the computer.

Closing: end of the day

  1. Close the demo
    with Ctrl + Shift + Q.
  2. Switch off the headset.
    Hold its power button until the Power menu appears, choose Power off. It can stay on its cable.
  3. Put the two controllers on charge
    with their own charging cable, so they start the day full.
  4. Shut down the computer and switch off the screen.
The headset charges slowly from the computer while streaming. For a full day of demos, charge it overnight so it starts the day full.

For the technician

START PC DEMO runs start-pc-demo.ps1: it checks the OpenXR runtime (registry HKLM\SOFTWARE\Khronos\OpenXR\1\ActiveRuntime), SteamVR, the HEVC extension, the film, the intro and the GPU, then starts visitor-station.ps1 -PcApp "MOI_PromiseOfSafety\MOI_PromiseOfSafety.exe". Options: -Check, -AppOnly (the experience alone, no station).

In PC mode the station starts the experience as a borderless window the size of the screen and uses it as the mirror, keeps it running, reads its status from %USERPROFILE%\AppData\LocalLow\GameX\MOI Promise of Safety\status.txt, and reads the button box on its COM port (PUSH_TO_PLAY, 9600 baud) or F9. Closing the station closes the experience.

The experience is a Unity 6 Windows build (OpenXR, DirectX 11). With no VR runtime at start it runs in a window capped at 60 fps and retries the runtime every 10 s. Its log writes the film’s real frame rate every 5 s, e.g. [MOI] Film 7680x3840 at 20 s: 30.0 fps, 0 frame(s) dropped.

Logs: logs\ in the demo folder (station) and Player.log next to status.txt (experience). Full notes: README-PC-DEMO.txt in the demo folder.
