`C:\Users\Lenovo\VR` is "The Promise of Safety" (وعد الأمان): a 3-minute passive VR journey for the UAE Ministry of Interior museum, pitched by Al Fakhr, built by the user's studio (GameX) for **VIVE Focus** (Focus 3 / Vision class, OpenXR + VIVE OpenXR Plugin 2.5.1, Unity 6000.1.4f1, URP). Source of truth is the 26-page storyboard deck `Downloads\UAE MINISTRY OF INTERIOR - MUSEUM VR EXPERIENCE.pdf` (18 beats, bilingual AR/EN voice-over, crystal as guide, museum bookends).

**Delivery model (user clarified 2026-09-21):** the visitor is in a virtual museum environment, clicks a button in VR, and **a video plays**. So the journey itself is expected to arrive as a finished film (flat or 360), not as real-time scenes. The project supports that via "Single-video delivery" on `Assets/MOI/Data/PromiseOfSafety.asset`; the per-beat real-time/previs path exists mainly for review until the film is supplied.

**Why:** avoids over-investing in real-time versions of the 2076 city beats, which a mobile XR2 headset could not render at storyboard quality anyway.

**Confirmed by user 2026-09-21:** the film is a **360° video covering the full 3:00** (museum opening and ending included). Mono vs stereo, resolution and producer still unknown. A Unity-encoded stand-in (`StreamingAssets/MOI_TestJourney360.mp4`, menu MOI > Review > Encode 360 Test Film) is assigned on the sequence and the START → 360 playback → return loop is verified in the editor only, not on a headset. Unity's Skybox/Panoramic puts the equirect centre at +X; `EnvironmentManager.FrontIsForward = 90` corrects it (−90 faces backwards — tested).
